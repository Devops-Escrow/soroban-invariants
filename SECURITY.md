# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of `soroban-invariants`.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `soroban-invariants` and the smart contracts tested with it seriously.

If you discover a security vulnerability or potential exploit, please do **NOT** open a public issue.

Instead, please report the vulnerability through **GitHub Private Vulnerability Reporting**:
1. Navigate to the repository on GitHub.
2. Click the **Security** tab.
3. Under "Reporting", click **Report a vulnerability** to open an advisory draft.

Your report will be reviewed confidentially. Please provide:
- A description of the issue and potential impact.
- Steps to reproduce or a minimal proof of concept test.
- Any suggested remediations or workarounds.

We will coordinate a fix and release a patched version with appropriate CVE / GitHub Advisory credit.
